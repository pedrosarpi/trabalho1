# Trabalho 1 - CRUD

Avaliação relacionada as Sprints 1 e 2. Foi desenvolvido um programa de computador, em linguagem Python, que permitr realizar operações de cadastro, consulta, atualização e remoção (CRUD) de ativos de TI e de vulnerabilidades associadas a esses ativos. A aplicação simula, de forma simplificada, uma base de inventário
de segurança utilizada por uma equipe de Computação ou Cibersegurança para acompanhar quais
equipamentos, sistemas ou serviços existem em uma organização, quais vulnerabilidades foram
identificadas neles e qual é a situação de tratamento dessas vulnerabilidades.
